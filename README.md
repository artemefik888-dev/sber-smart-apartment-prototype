# Умная квартира Sber × СберУслуги

Кликабельный адаптивный прототип интеграции услуги «Умная квартира Sber» в витрину ремонта СберУслуг. Это демонстрационный макет: он не отправляет заявки, не обрабатывает персональные данные и не является публичной офертой.

## Что реализовано

- карточка услуги на главной между «Капитальным ремонтом» и «Строительным контролем»;
- подробный раздел помощи в формате аккордеона;
- 18 состояний конструктора: 6 комнат × уровни «Базовый», «Комфорт» и «Максимум»;
- 6 готовых наборов с согласованными ценовыми ориентирами;
- решения S, M и L для всей квартиры с четырьмя дополнительными модулями и мгновенным пересчётом;
- новая услуга в калькуляторе ремонта, независимые состояния аккордеона и чекбокса;
- deep-link из любой карточки в калькулятор с предвыбором услуги;
- выбор всех услуг, снятие выбора, сохранение формы и шага в `localStorage`;
- три шага калькулятора, экран успеха и отдельная служебная схема процесса;
- локальный `dataLayer` с событиями прототипа.

## Маршруты

Прототип использует `HashRouter`, чтобы прямые переходы работали на GitHub Pages.

| Прототип | Будущий production URL | Назначение |
| --- | --- | --- |
| `#/` | `/` | Главная витрины ремонта |
| `#/help/services?section=smart-apartment` | `/help/services#smart-apartment` | Подробная страница услуги |
| `#/calculator` | `/calculator` | Калькулятор ремонта |
| `#/success` | `/success` | Успешная заявка |
| `#/flow` | `/flow` или внутренняя документация | Служебная схема handoff, не включена в клиентскую навигацию |

## Аналитика

События записываются только в `window.dataLayer` и консоль браузера. Внешних счётчиков нет.

| Событие | Когда отправляется | Основные параметры |
| --- | --- | --- |
| `smart_apartment_impression` | показ карточки или конструктора | `placement` |
| `smart_apartment_expand` | раскрытие подробностей | `placement`, опционально `set_id` |
| `smart_apartment_select` | выбор услуги | `placement`, опционально `preset` |
| `smart_apartment_deselect` | снятие выбора | `placement` |
| `smart_apartment_continue_selected` | переход со шага 1 с выбранной услугой | `selected_services` |
| `smart_apartment_submit` | отправка демонстрационной заявки | `smart_selected`, `city`, `rooms`, `area`, `source`, `preset` |
| `smart_apartment_handoff_flag` | формирование признака передачи профильному исполнителю | `handoff_required`, `service_id`, `source` |

Во все записи автоматически добавляются `prototype: true` и ISO‑время `timestamp`.

## Источники контента

Контент сверен по мастер‑промту проекта, ТЗ интеграции, контентной спецификации, материалам партнёрской программы и кикоффа, а также публичному макету Figma. При расхождениях приоритет отдавался мастер‑промту как более новой согласованной постановке.

Визуальный язык сопоставлен с публичной витриной [remont.sberuslugi.ru](https://remont.sberuslugi.ru/). Два локальных изображения и favicon получены с официальной публичной страницы [Умного дома Sber](https://sberdevices.ru/smarthome/); каталог вынесен отдельной внешней ссылкой на [официальный раздел устройств](https://sberdevices.ru/shop/category/smarthome/). Исходные презентации, документы и закрытые материалы в репозиторий не включены.

## Принятые решения и ограничения

- Цены наборов и решений соответствуют согласованным значениям из мастер‑промта. Противоречащие промежуточные цены из презентаций не использованы.
- Для решений по отдельным комнатам цена не показывается: в источниках нет однозначно согласованной полной стоимости каждого из 18 вариантов.
- Монтаж, проектирование и настройка рассчитываются отдельно после консультации.
- Нейтральные буквенные пиктограммы и текстовый партнёрский знак используются как элементы демонстрационного макета; закрытые бренд‑ассеты не копировались.
- Форма полностью статическая: серверной интеграции, CRM, авторизации, оплаты и реальной отправки лида нет.
- Данные формы хранятся только в `localStorage` текущего браузера.

## Локальный запуск

Требуются Node.js 24 и pnpm 12.

```bash
pnpm install
pnpm dev
```

Проверки и production‑сборка:

```bash
pnpm lint
pnpm typecheck
pnpm test
pnpm build
pnpm preview
```

GitHub Actions выполняет все проверки и публикует каталог `dist` через GitHub Pages.

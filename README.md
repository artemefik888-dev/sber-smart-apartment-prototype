# Умная квартира Sber × СберУслуги

Кликабельный адаптивный прототип встраивания услуги «Умная квартира Sber» в существующие страницы и клиентский путь витрины ремонта СберУслуг. Это демонстрационный макет: заявки и персональные данные никуда не отправляются.

## Что реализовано

- действующая структура главной страницы «Ремонт со СберУслугами» без отдельного промолендинга;
- одна стандартная карточка «Умная квартира Sber» после «Капитального ремонта» и перед «Приемкой квартиры»;
- deep-link из карточки к отдельной FAQ-группе с автоматически раскрытым первым вопросом;
- 21 существующий вопрос раздела «Услуги» и отдельная группа из 12 согласованных вопросов про Умную квартиру;
- готовые материалы шести комнат, шести наборов и трёх решений для всей квартиры внутри четвёртого ответа, без нового продуктового интерфейса;
- строка «Умная квартира Sber» в первом шаге калькулятора после «Капитального ремонта» и перед «Строительным контролем»;
- независимые стрелка раскрытия и чекбокс, выбор всех услуг, сохранение выбора на следующих шагах;
- согласованный экран успеха и отдельная служебная страница CJM;
- модульные и браузерные тесты для desktop и mobile.

## Маршруты

Прототип использует `HashRouter`, чтобы прямые переходы работали на GitHub Pages.

| Прототип | Назначение |
| --- | --- |
| `#/` | Главная витрина ремонта |
| `#/help/services?section=smart-apartment` | Раздел помощи; группа «Умная квартира Sber» |
| `#/calculator` | Калькулятор ремонта |
| `#/success` | Согласованный результат заявки |
| `#/flow` | Служебное приложение с CJM; в клиентскую навигацию не включено |

Для изображения карточки, обзорного изображения и ссылок на слайды 5–14 оставлены явно помеченные нейтральные заглушки до отдельного подтверждения права на публичное размещение этих материалов. Индивидуальные node-id для шести комнат в источниках не подтверждены, поэтому шесть подписанных ссылок ведут в один проверенный Figma-файл. Эти ограничения требуют уточнения перед production-реализацией.

Контакты поддержки в двенадцатом вопросе перенесены только из предоставленных материалов и требуют подтверждения владельцем поддержки перед реальным запуском.

## Вопросы второго релиза

Эти вопросы не смешаны с основной группой из 12 пунктов и требуют технической верификации:

- что необходимо для работы системы;
- какие функции сохраняются без интернета;
- можно ли подключить уже купленные устройства;
- какие устройства совместимы;
- какая гарантия действует на устройства и монтаж;
- кто отвечает за неисправность после передачи;
- сколько времени занимает проектирование, монтаж и настройка.

## Аналитика прототипа

События `smart_apartment_impression`, `smart_apartment_expand`, `smart_apartment_select`, `smart_apartment_deselect`, `smart_apartment_continue_selected`, `smart_apartment_submit` и `smart_apartment_handoff_flag` записываются только в локальный `window.dataLayer` и консоль браузера. Внешних счётчиков нет.

## Локальный запуск и проверки

Требуются Node.js 24 и pnpm 11.19.0.

```bash
pnpm install
pnpm dev
```

```bash
pnpm lint
pnpm typecheck
pnpm test
pnpm build
pnpm exec playwright install chromium
pnpm test:e2e
```

GitHub Actions выполняет статические проверки, production-сборку и Playwright-тесты в desktop- и mobile-профилях, после чего публикует `dist` через GitHub Pages.
